## 常见问题

### 香港大带宽为什么比美国贵这么多

贵在带宽成本和线路。香港本地国际出口昂贵，市面上香港 VPS 以三五兆为主流，大端口本身就稀缺；再叠一层 CN2 GIA 优化，价格还要翻几倍。搬瓦工香港 1Gbps 要 $90/月，而美国 10Gbps 只要几美元，差价几乎全在这。

### 标称 100M 或 10Gbps 能跑满吗

短时间可以，长时间很难。共享端口的结构决定了实际吞吐取决于同时在线的用户，晚高峰打折是常态。评估套餐时把标称值当上限，真正该问商家的是“晚高峰能稳在多少”。

### 大带宽 VPS 拿来做什么最值

持续吃带宽的用途最值：异地备份和同步、文件中转下载、流媒体中转、自建网盘。反过来，只是挂个低流量博客，5M 都绰绰有余，为它上大带宽属于花错钱。

### 月付和年付怎么选

能确认线路合适就年付。MKCloud 除最低配外年付直接减 20%，100M 档折后每月合 2 美元；线路没把握的话，先从月付档试水一两个月，确认满意再上目标的年付套餐，比一上来就年付一年稳妥。
